# Hardware

- ESP32 DOIT DEVKIT V1
- 6 FSRs, 3 per foot (toe, mid, heel), each in a voltage divider with a fixed resistor
- ADC1 pins (GPIO): 32, 33, 34, 39, 36, 35 = L toe, L mid, L heel, R toe, R mid, R heel
- Reads about 4095 unpressed; the reading falls as load rises
